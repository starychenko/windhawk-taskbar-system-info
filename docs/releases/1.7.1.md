# Taskbar System Info 1.7.1

This release brings the review fixes accepted in
[windhawk-mods PR #5921](https://github.com/ramensoftware/windhawk-mods/pull/5921)
into this repository's main branch and published source. The mod source matches
both the PR head `953b6dda8c39bd768753e75bce6af2565b0b0d6e` and its merged
revision `05168884e6fe6c3cbfa16abec0f2ccd6ab5e79cd` exactly as a Git blob.

## Changes since 1.7.0

- Moving is now opt-in: **Move widget hotkey** is empty by default. Choose an
  unused shortcut in settings before moving the widget. An explicitly configured
  shortcut is retained; no settings migration is required.
- Guard incomplete taskbar initialization, contain move-editor and monitor
  callback exceptions, and refuse native window classes owned by a previous
  module load. Failed class removal remains retryable.
- Release cached XAML resources on their owning thread. Retain reusable plain
  font measurements, skip unchanged placement work and bound drag geometry
  caching to 100 ms. Enter and timer paths still obtain fresh geometry.
- Unrelated Windows settings broadcasts no longer cancel moving. Display and
  work-area changes still cancel it.
- Keep all seven layout columns and verify actual arranged metric-row bounds.
  Remove unused state and the test-only renderer from production.
- Clarify shortcut conflicts and installation guidance, correct affected
  Ukrainian setting descriptions and update the regression fixtures.

The four automatic layouts, per-display positions and metric freshness/recovery
behavior from 1.7.0 remain. See the
[review resolution](../review-resolution-2026-10-04.md) for implementation details.

## Verification

Release checks were run on 2026-10-07 with Windhawk 1.7.3 / Clang 20.1.3:

- `python -B tests/validate-source.py`: version 1.7.1, 29 settings and source/documentation invariants passed.
- `./tests/run-regression.ps1`: 173,469 behavioral checks passed.
- `./tests/run-ui-smoke.ps1`: 105 XAML width/height/font cases, four layouts, five preview DPIs and 200,000 generated real-font geometries passed. All 192,913 visible previews preserved placement/layout after serialization; arranged bounds and teardown checks passed.
- `./tests/run-metrics-smoke.ps1`: read-only live Windows provider checks passed; both injected engine failures returned the expected exit code 5. Windows CPU thermal zones were unavailable.
- `./build.ps1 -OutputDirectory ./build-release-x64`: x64 build passed without warnings.
- `./build.ps1 -Architecture aarch64 -OutputDirectory ./build-release-arm64`: ARM64 cross-build passed without warnings.
- `git diff --check`: passed. The source Git blob matches the upstream PR and merged revision.
- Visual review: freshly rendered compact one-row/two-row layouts and valid/invalid move surfaces were readable, with all metric groups present.

No GitHub Actions workflows are configured in this repository.
Isolated tests and provider reads do not verify physical Explorer interaction,
Taskbar Styler presets, mixed-DPI monitor transfers, unplug/reconnect, restart
persistence, unload during editing or recovery from a real graphics-driver reset.
Those scenarios remain unverified in this release. ARM64 hardware is untested;
the mod metadata still targets Windows 11 x86-64.

## Install or update

Install or update **Taskbar System Info** through Windhawk. For a local source
copy, download **taskbar-system-info.wh.cpp**, replace the source in Windhawk's
mod editor, compile and enable it. To move the widget, first configure
**Move widget hotkey**, then use Enter to save or Esc to cancel.
