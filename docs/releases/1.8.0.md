# Taskbar System Info 1.8.0

This release adds optional network rates and widget copies on other monitors.
Both features are disabled by default, so upgrading preserves the existing
single-widget layout. No settings migration is required.

These notes cover all changes since v1.7.2, including its October 13 refresh.
The dock reservation fixes already shipped in that refresh are not new in 1.8.0.

## Network download and upload rates (#14)

- Enable **Show network speed** in the mod's Windhawk settings to display
  download and upload rates after RAM/VRAM. The widget adds the measured width
  of this column to the configured width and supports all four adaptive layouts.
- **Network speed unit** selects bytes per second (1024-based KB/s, MB/s, GB/s;
  default) or bits per second (1000-based Kbps, Mbps, Gbps). Units scale
  automatically, and both directions are included in the move preview.
- Rates are calculated from Windows interface counters over actual elapsed
  sample time and summed across active physical adapters. They include local
  network traffic; this is not an internet speed test or a per-application meter.
  Software loopback, filter and non-hardware interfaces are excluded.
- The first sample, missing adapters, reset counters and newly connected
  adapters establish a baseline instead of showing a false zero or a spike.
  Valid idle samples show zero; unavailable or stale readings show `--`.
- API errors reset the baseline. Interface table memory is released even if
  sample processing throws. Disabling the feature clears counter history.
- Collection uses local Windows APIs, with no packet inspection, telemetry or
  internet requests. The build links the Windows IP Helper library.

## Copies on other taskbars (#15)

- Enable **Show on all monitors** to add a copy on each other available taskbar.
  Windows must provide a taskbar on that display.
- **Taskbar monitor** and dragging still select the main widget. Secondary
  copies are read-only and use the display's saved position or **Left offset**.
  Dragging and space reservation before Start remain primary-widget features.
- Copies share metrics and settings, including the optional network column,
  while using their own taskbar theme and available space. Layout events can
  reposition a copy without waiting for another metrics sample.
- A shared widget factory, layout application, styling and value renderer keep
  primary and secondary rendering consistent. The public
  `Grid#WindhawkTaskbarSystemInfo` selector is preserved.
- Each instance owns its XAML objects, event subscriptions, timer and native
  window registration on its taskbar's UI thread. Cross-thread updates use
  immutable presentation snapshots rather than copying controls or temporarily
  replacing global renderer state.
- Copies expire stale readings while the main taskbar rebuilds. They are
  removed when disabled, promoted to the main widget, destroyed or unloaded;
  reconciliation also handles replacement of a taskbar's XAML root.
- During placement recovery, copies wait until the main taskbar is identified.
  An occupied XAML root rejects a second widget, preventing the duplicate found
  during review of the fallback/retry path.

## Verification

The release source was qualified after merging both feature PRs:

- Source/documentation validation: version 1.8.0, 32 settings.
- 173,515 behavioral regression checks.
- Complete isolated XAML UI smoke suite: 105 width/height/font cases, 200,000
  generated geometries, existing placement/reservation/move/stale-data cases,
  and a secondary widget on another UI thread.
- Production coordinator tests exercise native window enumeration and
  reconciliation, unknown/recovered/misidentified main taskbars, model/settings
  delivery, root replacement, disable/re-enable and window destruction. Only
  private Explorer frame lookup is replaced by a fixture.
- The recovery regression was also run without the two new guards: it fails
  on duplicate/premature creation; the corrected suite passes.
- Exact network values and byte/bit switching in primary, secondary and both
  preview fields; combined network/copies; high-contrast styling helpers.
- Light/dark isolated renders with network values visually checked.
- Local Windows metrics smoke, including injected failure cases; x64 build
  and ARM64 cross-build; `git diff --check`.
- Three reviewers checked the final feature fix without further actionable
  findings. No GitHub Actions workflows are configured in this repository.

UI tests use isolated XAML hosts, not injection into Explorer. The coordinator
fixture uses one UI thread; a separate fixture checks secondary dispatch to
another thread. Physical hot-plug, mixed-DPI monitors, Explorer restart,
native Windows high-contrast switching, third-party taskbar mods and ARM64
hardware remain unverified. High-contrast helper checks do not establish
native accessibility-mode behavior.

## Install or update

Download **taskbar-system-info.wh.cpp**, replace the source in Windhawk's mod
editor, compile and enable it. Open the mod's settings to enable either new
feature; both are off by default. This repository release does not itself
update the official Windhawk catalog or your installed mod.
