# Taskbar System Info 1.9.0

Choose the widget's preferred layout, hide CPU/GPU graphs independently, and
recover the space used by disabled temperatures. The widget still adapts when
the taskbar has less room and restores your preferred view when it fits again.

## Changes

- **Temperature source: Disabled** removes both temperature fields and their
  width, including space reserved before Start. Missing data from an enabled
  provider still displays `--°C`.
- **Show CPU graph** and **Show GPU graph** independently control the history
  graphs. Percentages stay visible and history keeps collecting while hidden.
  CPU and GPU share a column, so hiding just one graph can retain the same outer
  width. Hiding both removes the graph column and its gap.
- **Preferred layout** selects Full, Without graphs, Compact two rows, or
  Compact one row. Each taskbar independently fits the available space without
  bringing back details hidden in settings. Compact one row can use two rows
  when width is limited; a short taskbar can require one row.
- Main widgets, secondary copies and move previews use the same preferences.
  Content changes invalidate placement and reservation caches, including a
  previously rejected reservation. Equal-width CPU/GPU graph swaps refresh
  visibility correctly.

Full layout and both graphs remain enabled by default. Existing positions and
settings are preserved; no manual settings migration is required. Users who
already disabled temperatures will now get a narrower widget.

## Measured size examples

Isolated production-XAML renders with the default font, width setting 410,
network hidden and the documentation's sample readings:

| View | Width in logical pixels |
| --- | ---: |
| Full | 410 |
| Temperatures disabled | 370 |
| Both graphs disabled | 219 |
| Temperatures and both graphs disabled | 188 |
| Compact two rows, temperatures disabled | 142 |
| Compact one row, temperatures disabled | 286 |

Widths depend on font, memory capacities, network visibility and available
space. They are examples, not fixed switching thresholds. Screenshots and test
details are in the [verification record](https://github.com/starychenko/windhawk-taskbar-system-info/blob/v1.9.0/docs/layout-preferences-verification-2026-10-21.md).

## Remaining limits

This release was not installed into the live Explorer session. Actual taskbar
dragging, physical secondary displays, mixed-DPI transfers, monitor hot-plug,
restart persistence, ARM64 hardware and other live Styler configurations remain
unverified. Isolated XAML and native preview tests do not establish those flows.

## Install or update

Download **taskbar-system-info.wh.cpp** from this release. Replace the source
in Windhawk's mod editor, compile and enable it. Publishing this repository's
release does not automatically update the official Windhawk catalog or an
installed mod.
