# Taskbar System Info 1.8.1

**Refreshed on October 18, 2026.** This release now includes the fixes qualified
during upstream PR #6253 review. The version remains 1.8.1; its tag and attached
source replace the October 15 revision. If you downloaded 1.8.1 before this
refresh, download the source again and compile it in Windhawk's mod editor.

This patch fixes Taskbar Styler dock clipping and square backdrop borders,
reduces unnecessary secondary-taskbar discovery, and fixes a race during copy
cleanup and mod unload. No new settings or migration are required when updating
from 1.8.0 or the original 1.8.1. Optional network rates and widget copies remain
available through the existing settings.

## Changes

- **Taskbar Styler placement:** keep the theme's outer Grid column, span,
  alignment, Auto dimensions, margin and padding. Fit the inner Viewbox to the
  actual slot. Handle dynamic Auto docks, constrained Star/Pixel columns and
  theme removal/reapplication without competing placement or reservation writes.
- **Square backdrop borders:** render the zero-radius WindhawkBlur border
  through a clipped native Border. Refresh brush/radius-only changes and manage
  subscriptions on each widget's owning thread.
- **Secondary taskbar discovery:** discover after lifecycle/settings changes
  and retry temporarily unavailable taskbars with a bounded backoff. Ordinary
  metrics/watchdog updates reuse the existing widgets; copy timers consume
  shared readings. Detect a replaced XAML root before its Unloaded event.
- **Cleanup and unload:** stop timers/subclasses before revoking XAML callbacks,
  retain failed subscriptions for owner-thread retry, and remove dead HWNDs
  from the active registry. Remove registry ownership before clearing the HWND
  property so concurrent unload cannot queue a deleted controller. Failed
  native-destruction cleanup transfers ownership only once.
- **Network layout:** changing network visibility or byte/bit units resets a
  rejected dock-space reservation, allowing the new layout to be evaluated.
- Remove duplicate memory-bar updates and unused helpers, add the direct
  `<limits>` dependency, format the new code, and keep test hooks outside the
  distributed source. Add real-widget illustrations of network rates and copies.

## Remaining limits

The live session had one active monitor. Real secondary-taskbar creation/removal,
physical hot-plug, mixed-DPI transfers, ARM64 hardware and other Windows/Styler
combinations remain unverified. The isolated tests cover concurrent secondary
cleanup and recovery after repeated revocation failures; arbitrary permanent COM
failures or an inaccessible owner thread can still leave incomplete cleanup.
The square-backdrop workaround is targeted and does not establish compatibility
with every Styler configuration.

## Install or update

Download **taskbar-system-info.wh.cpp** from this release, replace the source in
Windhawk's mod editor, compile and enable it. Because the version number remains
1.8.1, an installation of the earlier 1.8.1 needs this manual source update.
Publishing this release does not update an installed mod or the official catalog.
