# Getting help

Start with the [README](README.md), especially
[troubleshooting](README.md#troubleshooting) and
[compatibility](README.md#compatibility). Temperature setup, unavailable readings
and adaptive layout behavior are described there.

For a bug, feature request or setup question, search the
[issues](https://github.com/starychenko/windhawk-taskbar-system-info/issues)
before opening a new one. Use the bug report or feature request template when
it fits; a blank issue is available for questions.

Include the mod and Windhawk versions, Windows build, CPU/GPU models and the
settings needed to reproduce the problem. For placement problems, include
monitor count, resolution, scaling, taskbar position and other taskbar mods.
Attach a screenshot and relevant Windhawk log lines when useful.

Remove personal information from screenshots and logs. For suspected security
vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of posting details
in a public issue.
