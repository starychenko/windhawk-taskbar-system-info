# Security reports

Do not post exploit details, sensitive logs or proof-of-concept code in public
issues or pull requests.

If GitHub offers **Report a vulnerability** on this repository's
[Security advisories page](https://github.com/starychenko/windhawk-taskbar-system-info/security/advisories),
use that private reporting form. If it is unavailable, open an
[issue](https://github.com/starychenko/windhawk-taskbar-system-info/issues)
asking for a private security contact, without describing the vulnerability.
Wait for a private channel before sharing technical details.

In a private report, include:

- The affected mod version or commit, Windhawk version and Windows build.
- Reproduction steps and any required settings or local access.
- The expected and observed behavior, and the security impact.
- A minimal proof of concept, if available, with personal data removed.

Check whether the issue also affects the current source and note the result.
Ordinary display, placement and unavailable-reading bugs belong in the
[bug tracker](https://github.com/starychenko/windhawk-taskbar-system-info/issues).
